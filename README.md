# Kamyar Inanloo GitHub Page

Static portfolio page built from Kamyar Inanloo's resume, LinkedIn URL, and public GitHub profile/repository metadata.

## Files

- `index.html` - main portfolio page
- `styles.css` - responsive visual design
- `script.js` - mobile navigation toggle
- `assets/avatar.jpg` - local GitHub avatar image

## Publish on GitHub Pages

1. Unzip this package.
2. Copy the files into the root of `kamyar1979.github.io`.
3. Commit and push to the `main` branch.
4. In GitHub, confirm Pages is enabled for the repository.

The page is dependency-free and can also be previewed locally by opening `index.html` in a browser.
